# 筆記用の三点持ち

既存の男の子（child-makehuman.glb）の骨格を使用。GRABなど第三者の動作データは使用していない。

指先だけを合わせる制御では皮膚が鉛筆へ食い込むため、スキニング後の皮膚表面に合わせて指関節を調整し、ローカル回転をwriting-grip.mjsへ保存した。皮膚や骨の長さは変更しない。

scripts/pencil-clearance.mjsは人物の皮膚・衣服など全32,994三角形を変形後の位置へ変換し、鉛筆の有限な軸線との最短距離を求める。軸部分は六角形を包含する半径3.5mmの円柱、木部と芯はそれぞれの最大半径で保守的に検証する。親指・人差し指・中指については近接も確認し、鉛筆を単に手から離して検証を通すことを防ぐ。

このポーズは現在の児童モデルと鉛筆寸法専用。モデル・骨格・寸法を変更した場合は再調整と検証が必要。一般的な衝突回避エンジンではない。

検証: node --test scripts/character.test.mjs
