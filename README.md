# 3d-ryokan

GitHubリポジトリ：https://github.com/yggdrasilw-spec/3d-ryokan

児童が身体や身近な物との比較を通じて、長さ・重さ・液体のかさの量感を学ぶHTML教材の作業フォルダ。

## 制作方針

- ユーザーは毎日作業時間を取れない前提。AIが調査、制作、検証、データ整理を担当し、確認はまとまった試作品で行う。
- Blenderの操作習得をユーザーに求めない。導入後はPythonスクリプトによる制作・寸法調整・GLB出力を目指す。
- ブラウザで使えるHTMLアプリとし、将来URLで共有する。公開は別途行う。
- 利用可能な既存3Dモデルを優先する。探索・修正の手間が大きければ、資料に基づきAIがBlender用スクリプトを作成する。
- 既存素材は商用利用の可否だけでなく、改変・Webアプリへの同梱と再配布・クレジット条件を確認する。配布元、作者、ライセンス、確認日を保存する。
- 寸法・重量・容量は推測を確定値として扱わず、製品資料や実測、対象の状態とともに記録する。

## 教材の範囲

### 長さ

- 身長130cmで子供らしい頭身の児童モデルを基準にする。
- 定規、ボールペン、机、牛乳パックなどを比較する。
- 全身との比較と、1cm・1mmを見る拡大表示を分ける。
- モデルの実寸比率と画面上の物理的な実寸は別物。拡大表示を明示し、必要なら実物の定規による表示調整を用意する。

### 重さ

- 予想、天秤での比較、基準の重り何個分かを確かめる流れ。
- 容器の空・中身入りなど、状態を区別する。
- 画面だけでは重さの感覚を直接再現できないため、実物を持つ活動と結びつける。
- 過去の会話中の牛乳パックの重量例は矛盾を含むため、教材データとして転記しない。

### 液体のかさ

- 1dLます、1Lます、10mLの注射器、形の違う容器を扱う。
- 10mLを10回で100mL＝1dL、1dLを10杯で1Lになることを操作で確かめる。
- 同じ量を細長い容器と平たい容器に移し、水面の高さと量を区別する。
- 容器の容量と、現在入っている液体の量を区別する。
- 透明な容器、水面、目盛りを見やすくし、目盛りを読む正面表示を設ける。
- 容量だけから容器の外形寸法を決めない。内形と水量に対応した水面を表示する。

## 初版の目標

130cmの児童と身近な物を比較し、長さ・重さ・かさを予想して確かめられる、小規模なブラウザ教材。
自由に試すモードと授業で順に見せるモードを検討する。初版はログインなしを基本とする。

## データの蓄積先

- `docs/`：計画、調査結果、制作記録
- `data/`：寸法・重量・容量、出典、素材のライセンス情報
- `models/`：Blenderファイル、GLBなどのモデル
- `scripts/`：モデル生成・書き出し・検証スクリプト
- `app/`：HTML教材

## 現在の状態

2026-09-10：操作できる3Dプロトタイプ「くらべるラボ」を実装。

### 起動

Windowsでは `start.cmd` をダブルクリックします（Python 3が必要）。起動したサーバーのウィンドウは開いたままにしてください。

コマンドで起動する場合：

```powershell
python scripts/serve.py
```

ブラウザで http://127.0.0.1:8317/app/ を開きます。3D版はローカルサーバーが必要です。外部サービス・npmインストール・ログインは不要。ライブラリも同梱しているためネット接続なしで動作します。

### 体験できること

- 身長130cmのキャラクターが机へ歩き、ものさし・えんぴつ・牛乳パックを手に持つ。机へもどす動作。
- 全体から手元への滑らかなカメラ移動、ドラッグで回転、ホイールでズーム。
- 実物の定規で5cmの線を調整して、正面の物を画面上の実寸で表示。収まらない部分は拡縮せずドラッグで移動。
- 水200Lのおふろに水着で入り、座って、また出る。
- 1L・10L・50Lの注水、排水、200Lの基準量への復帰。
- 10cm角＝1Lのブロック200個を、おふろと同じ縮尺で比較。
- 旧版の長さ・天秤・mL/dL教材は `app/classic.html`（画面の「重さ・基本教材」）に保存。

### 寸法の扱い

Three.jsの1単位＝1m。定規30cm、えんぴつ18cm、机高70cm。製品・身体の形状は自作の教材用モデルで、実測・製品資料に基づく値ではありません。

おふろ内寸は125×64×45cm。無人で200Lなら水深25cm。200Lは学習用の水量であり、浴槽の満水容量（360L）ではありません。入浴時の排除体積は簡略化しています。比較用の1Lブロック200個は現在の注水量から独立した200Lの基準表示です。

実寸は平行投影の画面寸法をCSS px/mmで校正します。設定はこのブラウザのlocalStorageへ保存。モニターやブラウザ倍率が変わったら再校正が必要です。物理的な実寸精度はユーザーが実物の定規で合わせた精度に依存します。画面に合わせて自動縮小することはありません。

### 検証

```powershell
node --test scripts/units.test.mjs
node --check app/studio.js
```

水量から水深への換算、実寸の画面サイズ非依存、無効な校正値を検証します。操作・表示はブラウザで別途確認します。
